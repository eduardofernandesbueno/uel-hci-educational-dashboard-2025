# Interface - Visualização de Dados Educacionais, Mestrado UEL (2025-2027)

Repositório dedicado ao desenvolvimento da interface gráfica para visualização dos resultados do projeto "Análise de Dados Educacionais em Instituições de Ensino Superior, UNIVESP, 2021-2025 (TCC, Ci6encia de Dados)", utilizando Streamlit e visualizações computacionais.

---

## 📚 Contexto

Este repositório faz parte da Atividade Prática 1 da disciplina **Interface Homem-Computador** do **Mestrado em Computação da UEL (Turma 2025/1)**, ministrada pela Profª **Vanessa Tavares de Oliveira Barros**.

Trabalho a ser apresentado em:
- Apresentação 1: 06/05/2025
- Apresentação 2: 21/05/2025
- Entrega Final: 28/05/2025

---

## 🎯 Objetivo

Desenvolver uma aplicação visual, acessível e interativa para análise e interpretação dos dados de ingresso, permanência e evasão de alunos em Instituições de Ensino Superior, com foco em melhorar a usabilidade e a acessibilidade da interface.

---

## 🛠️ Tecnologias Utilizadas

- **Python 3.11+**
- **Streamlit** — construção de aplicações web interativas
- **Matplotlib** — geração de gráficos estáticos e interativos
- **Pandas** — manipulação de dados
- **HTML/CSS** — personalização de layout e estilo
- **VS Code** — ambiente de desenvolvimento
- **GitHub** — versionamento e colaboração

## 🚀 Como Executar Localmente

### 1. Clone o repositório:

```bash
git clone https://github.com/EddieFerb/interface.git
cd interface
```

### 2. Crie e ative o ambiente virtual:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requisitos.txt
```

### 3. Rode a aplicação Streamlit:

```bash
streamlit run /interface/scripts/dashboard/app_evasao.py
```

- Filtros por curso, ano e modalidade (presencial/EAD).
- Exportação de gráficos em formato `.png` e `.html`.
- Dashboard dinâmico e responsivo em Streamlit.
