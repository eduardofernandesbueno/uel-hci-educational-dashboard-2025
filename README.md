## Overview

This academic project investigates the usability, accessibility, and interaction design of a higher education analytics dashboard developed to visualize student admission, completion, and dropout indicators.

Conducted as part of the Human–Computer Interaction course at the State University of Londrina (UEL) in 2025, the work combines heuristic usability evaluation, accessibility analysis, interface design, and exploratory implementation of accessible web components.

The study examines how educational analytics systems can communicate complex information more effectively, particularly to users with low vision, color vision deficiencies, or blindness.

The dashboard used as the initial case study originated from a collaborative 2025 UNIVESP Data Science capstone project. The subsequent UEL coursework focused specifically on the human–computer interaction and accessibility dimensions of that system.

## Objectives

- Evaluate the usability of an educational analytics dashboard using Jakob Nielsen's ten usability heuristics.
- Identify accessibility barriers affecting users with visual disabilities.
- Analyze relevant requirements from the Web Content Accessibility Guidelines (WCAG) 2.2.
- Explore accessible navigation, interface feedback, content structure, and data visualization.
- Investigate assistive technologies and alternative representations of graphical information.
- Document design limitations, improvements, and opportunities for future development.

## Human–Computer Interaction Methodology

### 1. Heuristic Usability Evaluation

The project examined the educational dashboard using Jakob Nielsen's ten usability heuristics.

Areas of investigation included:

- Visibility of system status
- Match between the system and the real world
- User control and freedom
- Consistency and standards
- Error prevention
- Recognition rather than recall
- Flexibility and efficiency of use
- Aesthetic and minimalist design
- Error recognition and recovery
- Help and documentation

The evaluation identified potential improvements related to loading feedback, navigation, information presentation, form interaction, error messages, and documentation.

### 2. Accessibility Analysis

The study considered the four WCAG 2.2 principles:

- **Perceivable:** alternative descriptions, readable content, and appropriate visual contrast.
- **Operable:** keyboard navigation, visible focus, and consistent controls.
- **Understandable:** meaningful labels, contextual assistance, and clear feedback.
- **Robust:** semantic markup and compatibility considerations for assistive technologies.

The analysis focused particularly on visual accessibility for users with low vision, color vision deficiencies, and blindness.

### 3. Accessible Interface Design

The coursework documented and explored improvements such as:

- Light, dark, and high-contrast interface alternatives
- Keyboard-accessible navigation
- Semantic HTML and ARIA attributes
- Contextual help and descriptive labels
- Accessible feedback and error messages
- Responsive layout considerations
- Textual descriptions of charts
- Voice-assisted navigation using browser speech capabilities

Implementation maturity varies across these features. Some were demonstrated in prototypes, while others remained recommendations or future work.

### 4. Accessible Data Visualization

The project investigated how educational indicators could be presented beyond conventional visual charts.

Topics included textual chart descriptions, color-independent visual encoding, accessible tables, assistive technologies, and data sonification as a prospective approach.

## Educational Analytics Context

The evaluated dashboard uses the Brazilian Higher Education Census (INEP/MEC) as its domain context.

The underlying system supports analysis of educational indicators, including:

- Student admissions
- Completion rates
- Student dropout rates
- Historical trends
- Comparisons across undergraduate programs

The objective of the HCI project was to evaluate and improve the presentation and interaction of these indicators, not to claim a new independent predictive machine learning benchmark.

## Findings and Limitations

The academic evaluation identified usability and accessibility concerns involving:

- Insufficient interface feedback
- Small text and inadequate visual contrast
- Charts without suitable nonvisual alternatives
- Inconsistent or insufficient assistance for users
- Limitations in keyboard and assistive-technology interaction

The work documented potential remedies and exploratory interface enhancements.

**Limitations:** This repository represents academic coursework and exploratory engineering. It does not constitute an independently certified WCAG 2.2-compliant application, a completed accessibility conformance audit, or a production-ready institutional service.
